**ponytail**은 DietrichGebert가 개발한 오픈소스 AI 에이전트 플러그인(스킬셋)이다. 

**"최고의 코드는 작성하지 않은 코드(The best code is the code you never wrote)"**라는 철학을 바탕으로, AI 코딩 에이전트(Claude Code, Codex, Cursor, Gemini CLI, Copilot 등)가 불필요한 과잉 설계(Over-engineering)를 피하고 **가장 단순하고 직관적인 코드를 작성하도록 유도**하는 도구이다.

## 1. 주요 작동 방식 (6단계 점검)
AI가 코드를 작성하기 전에 다음과 같은 단계를 거쳐 스스로 동작을 멈추거나 코드를 최소화하도록 만든다.
1. **진짜 필요한 기능인가?** (YAGNI 원칙에 따라 필요 없다면 스킵)
2. **표준 라이브러리(Standard Library)로 해결 가능한가?**
3. **네이티브 플랫폼 기능이 존재하는가?**
4. **이미 설치된 의존성(Dependency)으로 해결할 수 있는가?**
5. **한 줄로 처리할 수 있는가?**
6. **최소한의 코드만 작성** (단, 보안, 데이터 손실 처리, 접근성 등 필수적인 안전망은 절대 생략하지 않음)

> **비교 예시:**
> * **일반 AI 에이전트:** 날짜 선택기(Date Picker) 구현을 요청하면 외부 라이브러리 설치, 컴포넌트 래핑, 스타일시트 적용 등 복잡한 코드를 수백 줄 작성함
> * **ponytail이 적용된 AI:** 브라우저 네이티브 기능인 `<input type="date">` 한 줄로 단순하게 처리함

## 2. 주요 기능 및 명령어
- **`/ponytail [lite|full|ultra|off]`**: 강도를 조절하여 적용한다.
- **`/ponytail-review`**: 현재 작업 중인 코드 차이점(diff)을 검토하여 과잉 설계된 부분을 찾아내고 삭제할 수 있는 목록을 제시한다.
- **`/ponytail-audit`**: 저장소(Repository) 전체를 스캔하여 오버 엔지니어링된 불필요한 코드를 찾아내고 단순화하거나 삭제할 수 있는 제안을 제공한다.
- **`/ponytail-debt`**: 코드 내에 미뤄둔 작업 주석(`ponytail:`)들을 수집하여 기술 부채 장부로 관리해 준다.
- **`/ponytail-gain`**: 이 도구를 통해 절약된 코드 라인 수, 비용 절감액, 속도 향상 지표 등을 측정하여 보여준다.

## 3. 기대 효과
저장소 편집 작업 측정 결과에 따르면, 이 플러그인을 적용했을 때 다음과 같은 효과를 얻을 수 있다고 밝히고 있다.
- **코드량 대폭 감소** (불필요한 과잉 설계 방지로 코드 복잡도 완화)
- **비용 절감 및 속도 향상** (불필요한 코드를 덜 생성하므로 AI API 토큰 사용량이 줄어들고 결과물 도출이 빨라짐)

과도한 추상화나 불필요한 라이브러리 도입을 지양하고, 최대한 가볍고 유지보수하기 쉬운 결과물을 내고 싶을 때 유용하게 활용할 수 있는 AI 프롬프트 가이드라인 및 개발 도구 패키지이다.
