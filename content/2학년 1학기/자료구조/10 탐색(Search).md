## 1. 해싱(Hashing)
|   Search    |  Best  | Average | Worst  |
| :---------: | :----: | :-----: | :----: |
| **Hashing** | $O(1)$ | $O(1)$  | $O(n)$ |

- **Hashing**
	- 임의의 크기를 가진 데이터를 고정된 크기의 해시값으로 변환하는 기술
	- 주소 해시 함수를 사용하여 입력 데이터를 계산하고, 결과값을 해시 테이블에 저장하거나 조회한다.
	- **구조**: 키 → `[해시 함수]` → 해시 주소 → `[해시 테이블]`(버킷×슬롯)
	- **삭제 처리**: 사용 전 빈 슬롯(0) vs 사용 후 빈 슬롯(-1) 구분

- 특징
	- **장점**: 빠른 탐색 속도 (평균 $O(1)$, 최악 $O(n)$)
	- **단점**: 정렬 불가, 공간 낭비 가능성과 ==충돌(Collision)== 문제
- **활용**: 데이터 검색, 암호화, 데이터 무결성, 부하 분산, 캐싱, 블록체인
	- *암호학적 해시는 충돌과 역추적이 불가능하고 입력 변화에 민감한 것이 핵심이다.*

### 1.1. Collision
- **충돌**(collision)/동의어(synonym): 서로 다른 키가 같은 주소로 계산되는 상황
- **오버플로**(overflow): 충돌이 슬롯 수 초과

#### (1) 개방 주소법
- **개방 주소법**(open addressing): 선형 조사, 이차 조사, 이중 해싱
	- 선형 조사(linear probing): `h(k), h(k)+1, …`

- **+ 클러스터링 완화**
	- 이차 조사(quadratic probing): `h(k)+1², +2²,…`
	- 이중 해싱(double hashing): 두 번째 해시 함수 이용

#### (2) 체이닝
- **체이닝**(chaining): 버킷을 연결 리스트 구조로 변경 → 무한 충돌 수용

### 1.2. 해시 함수
- **좋은 해시 함수**: 빠른 계산, 적은 충돌, 고르게 분포
- **종류**: 제산(나누기→소수) 함수, 폴딩 함수, 중간 제곱 함수, 비트 추출 방법, 숫자 분석 방법

## 2. 트리를 이용한 탐색
### 2.1. AVL 트리
- ==AVL 트리==: 균형+BST
	- Adelson-Velskii와 Landis
	- 이진 탐색 트리(BST)에 **균형 인수**(왼쪽/오른쪽 높이의 차)를 `-1`~`1`로 유지
    - LL, RR, LR, RL 회전으로 삽입/삭제 시 균형 복구
    - 모든 연산 O(log n)

1. **트리를 이용한 탐색(AVL 트리)**: 이진 탐색 트리의 균형을 유지하기 위해 회전 연산을 수행하여 모든 연산을 O(log n)으로 보장하는 구조까지 살펴봅니다.

- 균형이 깨지는 네가지 경우 -> **회전 연산**
    - **LL 회전**: 왼쪽 자식의 왼쪽 서브트리 삽입 시
    - **RR 회전**: 오른쪽 자식의 오른쪽 서브트리 삽입 시
    - **LR 회전**: 왼쪽 자식의 오른쪽 서브트리 삽입 시
    - **RL 회전**: 오른쪽 자식의 왼쪽 서브트리 삽입 시

- **삽입 예시**: `[7, 8, 9, 2, 1, 5, 3, 6, 4]` 순서로 삽입하며 균형 유지

- **연산 복잡도**: 삽입·삭제·탐색 모두 O(log n)
