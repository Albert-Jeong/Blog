## 1. 혼동행렬
|   혼동행렬    | **실제 양성 Class** | **실제 음성 Class** |
| :-------: | :-------------: | :-------------: |
| **예측 양성** |       TP        |   FP(==오탐==)    |
| **예측 음성** |   FN(==미탐==)    |       TN        |
- **혼동행렬**(confusion matrix)
	- 분류 모델의 성능을 평가할 때 사용하는 표
	- 모델이 예측한 결과와 실제 정답 간의 관계네 가지 경우의 수로 분류
	- 주로 이진 분류(Binary Classification)에서 사용

- 예시 시나리오
	- 의료 진단: FN을 줄여 질병을 놓치지 않도록 재현율을 중점 평가
	- 스팸 필터링: FP를 줄여 정상 메일을 스팸으로 오분류하지 않도록 정밀도 개선

## 2. 평가 지표
### 2.1. 지도학습(분류)
|          지표          |         핵심 질문         |       수식/정의(요약)        |       언제 유용한가?       |         주의사항         |
| :------------------: | :-------------------: | :--------------------: | :------------------: | :------------------: |
|       Accuracy       |     전체 중 몇 % 맞췄나?     |      (TP+TN)/(전체)      |     클래스 균형·투표모델      |     불균형 데이터에 취약      |
|      Precision       | 예측한 **양성** 중 진짜 양성 비율 |       TP/(TP+FP)       |    스팸필터·의료후양성비용 ↑    |  Recall과 trade-off   |
| Recall (Sensitivity) |    진짜 양성 중 얼마나 잡았나    |       TP/(TP+FN)       | 질병진단·결함탐지처럼 놓치면 큰 손해 | Precision과 trade-off |
|       F1-score       |       P·R 조화평균        |       2PR/(P+R)        | 불균형 데이터, 하나의 스칼라 필요  | 클래스별, micro/macro 선택 |
|       ROC-AUC        |    임계값 전 구간에서 구분력     |    곡선 아래 면적(0.5-1)     |  임계값 자유·클래스 불균형 완화   |      확률적 예측 필수       |
|        PR-AUC        |       PR 곡선 면적        | Precision-Recall 곡선 면적 |  극심한 불균형(IoT 침입탐지)   |     낮은 FP 영역 강조      |

- **정확도(Accuracy)**
	- 전체 예측 중 맞춘 비율(**전체 중 True의 비율**)
	- $Accuracy = \frac{TP+TN}{TP+FP+FN+TN}$

- **정밀도(Precision)**
	- Positive로 예측한 것 중 실제 Positive 비율(**예측 Positive 중 True의 비율**)
	- $Precision = \frac{TP}{TP+FP}$

- **재현율(Recall)**
	- 실제 Positive 중 올바르게 예측한 비율(**실제 Positive 중 True의 비율**)
	- $Recall = \frac{TP}{TP+FN}$

- **F1 Score**
	- 정밀도와 재현율의 조화 평균
	- $F1 = 2×\frac{Precision×Recall}{Precision+Recall}$
