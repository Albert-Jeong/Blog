- 안드레 카파시(Andrej Karpathy)는 OpenAI의 공동 창업자이자 전 테슬라 AI 디렉터로, 실무 중심의 AI 엔지니어링과 교육 분야에서 독보적인 방법론을 제시해 왔다.

## 1. 인공신경망 학습 레시피 (A Recipe for Training Neural Networks)
카파시는 "신경망 학습은 일반적인 코드 버그와 달리 에러 메시지 없이 조용히 실패(Fail silently)하는 특성이 있다"고 지적하며, 모델을 체계적으로 학습시키기 위한 5단계 방법론을 제시했다.

- **1단계: 데이터와 하나가 되기 (Become one with the data)**
	- 모델링을 시작하기 전에 수백 개의 데이터 샘플을 직접 눈으로 확인한다.
	- 데이터의 분포를 파악하고, 라벨링 오류나 노이즈, 특이값(Outlier)을 직접 찾아내며 데이터의 특성을 깊이 이해해야 한다.

- **2단계: 엔드투엔드 파이프라인 및 단순한 베이스라인 구축 (Set up end-to-end skeleton + dumb baselines)**
	- 처음부터 복잡한 모델을 쓰지 않고, 가장 단순한 모델과 기본 데이터로 '입력-학습-평가-출력'으로 이어지는 전체 파이프라인을 먼저 연결한다.
	- 이 단계에서는 고정된 랜덤 시드(Seed)를 사용해 결과를 재현 가능하게 만들고, 시스템 자체에 버그가 없는지 검증한다.

- **3단계: 단일 배치로 과적합 시키기 (Overfit one batch)**
	- 단 몇 개의 데이터(예: 2개~수십 개)만으로 구성된 아주 작은 데이터셋으로 모델을 학습시켜 본다.
	- 이때 손실(Loss) 함수가 0에 가깝게 떨어지며 완벽히 과적합(Overfitting)되는지 확인한다.
	- 이것이 불가능하다면 모델 아키텍처나 그래디언트 계산 등에 수학적 버그가 있음을 의미한다.

- **4단계: 규제화 및 일반화 (Regularize / Generalize)**
	- 과적합이 확인되면 모델의 크기를 키우고 실제 데이터셋 전체를 적용한다.
	- 학습 오차(Training loss)와 검증 오차(Validation loss) 사이의 격차를 줄이기 위해 데이터 증강(Data augmentation), 드롭아웃(Dropout), 가중치 감쇠(Weight decay) 등의 규제 기법을 점진적으로 적용한다.

- **5단계: 하이퍼파라미터 튜닝 및 최적화 (Tune / Optimize)**
	- 학습률(Learning rate), 배치 크기 등을 세부 튜닝하며 모델의 성능을 한계까지 끌어올린다.

## 2. '밑바닥부터 구현하기' 개발 및 교육 방법론 (From Scratch Philosophy)
카파시는 파이토치(PyTorch)나 텐서플로우(TensorFlow) 같은 대형 프레임워크의 고수준 API 뒤에 숨겨진 내부 동작을 깊이 이해해야 진정한 디버깅이 가능하다고 강조한다.

- **동작 원리의 내재화**
	- 그는 교육 과정('Zero to Hero' 시리즈 등)에서 복잡한 라이브러리를 쓰지 않고, 아주 기초적인 연산(Python 기본 문법과 수학)만으로 역전파(Backpropagation) 엔진(`micrograd`)이나 GPT 모델(`nanoGPT`)을 직접 구현하는 방식을 고수한다.

- **추상화 경계 허물기**
	- 기술의 추상화 계층 아래에서 어떤 일이 일어나는지 명확히 알아야 세밀한 최적화와 에러 추적이 가능하다는 관점이다.

## 3. 소프트웨어 2.0 (Software 2.0)
카파시가 정의한 소프트웨어 패러다임의 변화로, 현대 AI 개발을 바라보는 시각을 담고 있다.

- **소프트웨어 1.0 (전통적 코딩)**
	- 사람이 직접 규칙과 조건문(C++, Python 등)을 손으로 작성하여 프로그램을 만든다.

- **소프트웨어 2.0 (데이터 기반 코딩)**
	- 인간은 목표(코드의 아웃풋 지향점)와 데이터(학습 데이터셋)만 제공하고, 구체적인 조건문과 로직(신경망의 가중치 파라미터)은 수치 최적화(Gradient Descent)를 통해 컴퓨터가 스스로 찾아내게 만든다.

- 따라서 AI 엔지니어의 핵심 역할은 '코드를 직접 작성하는 것'에서 **'양질의 데이터를 수집, 라벨링, 정제하고 학습 인프라를 설계하는 것'**으로 전환된다는 철학이다.
