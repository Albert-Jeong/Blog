## 1. 프로그래밍의 이해
### 1.1. 컴퓨터
- **컴퓨터의 특징**
	- 대단히 유연한 기계
	- 소프트웨어만 바꾸면 리포트 작성부터 게임, 복잡한 계산까지까지 다양한 작업을 할 수 있다.
	- 단순 반복 작업은 컴퓨터가 인간보다 월등히 잘 수행한다.

### 1.2. 프로그램
- **프로그램(program)**
	- 컴퓨터가 수행할 **명령어**(instruction)들을 적어놓은 문서(작업지시서)
	- 예를 들어 로봇에게 사각형을 그리게 하려면 "100픽셀 전진 → 90도 회전"을 반복하는 지시사항이 필요하다.

- **프로그래밍의 필요성**
	- 이공계·인문사회계 구분 없이 필수적인 기술이 되었다.
	- 인공지능, 로봇 프로세스 자동화(RPA) 등 단순 반복 업무는 점점 컴퓨터가 맡게 된다.

- **프로그래밍 언어**
	- 컴퓨터는 사람의 말을 이해하지 못하고 **기계어**만 이해한다.
	- 그래서 사람은 **프로그래밍 언어**로 작성하고, **컴파일러(또는 인터프리터)**가 이를 기계어로 번역해 준다.
	- 프로그램을 만드는 사람 = **프로그래머**
	- 대표 언어로 파이썬, 자바, C, BASIC 등이 있다.

## 2. Python 소개
- **파이썬**
	- 1991년 **귀도 반 로섬(Guido van Rossum)**이 개발한 대화형 언어

- **특징**
    - **생산성**
	    - 문법이 간결하고 쉬워 프로그램을 빠르게 작성할 수 있다.
	    - C의 여러 줄짜리 Hello World가 `print("Hello World!")` 한 줄이면 끝
    - **인터프리터 언어**
	    - 코드를 한 줄씩 실행하고 결과를 즉시 확인할 수 있어 초보자에게 적합
    - **라이브러리**가 풍부하고 설치가 쉽다.
	    - 데이터 과학(Matplotlib, Pandas)
	    - 인공지능(Keras)
	    - 웹 크롤링(Requests)
	    - OpenCV, scikit-learn, BeautifulSoup 등

### 2.1. Python 개발 환경
- **아나콘다(Anaconda)**
	- 인기 라이브러리(numpy, pandas, scipy, sklearn 등)가 거의 다 포함된 배포판
	- 설치가 쉽고 관리가 편하다.
	- anaconda.com에서 내려받아 설치

- **스파이더(Spyder)**
	- 파이썬으로 만들어진 개발 도구(IDE)
	- 에디터, IPython 콘솔, 변수 탐색기, 프로파일러, 디버거, 도움말 제공

- **Jupyter Notebook**
	- 웹 브라우저 상에서 코드 실행과 설명(문서)을 함께 작성할 수 있는 도구
	- 코드와 설명(마크다운)을 한 문서에 담는 환경

- **Google Colab**
	- 클라우드 기반의 주피터 노트북 환경으로 별도 설치 없이 사용 가능하다.
	- 브라우저에서 실행되고 구글 드라이브에 저장·공유된다.

### 2.2. 기초 문법
- **print() 함수**
	- 텍스트를 화면에 출력
	- `print("결과값은", 10, "입니다.")`처럼 여러 값을 나열 가능

- **문자열(string)**
	- 큰따옴표 `"..."` 또는 작은따옴표 `'...'` 안의 텍스트 데이터
	- 따옴표가 없으면 `SyntaxError: invalid syntax`
    - `"나의 " + "고양이"` → 연결
    - 문자열 덧셈(연결)과 곱셈(반복)이 가능
	    - 예: `"Hello" * 10` → 반복

- **기본 연산**
	- 사칙연산(`+`, `-`, `*`, `/`) 및 거듭제곱(`**`) 지원
		- `3.14 * 10**2` → 314.0
	- `import math`를 통해 삼각함수, 제곱근, 로그함수 등 사용 가능
		- `math.sqrt(9.0)`, `math.log(1.0)` 등

- **문법 오류(SyntaxError)**
	- 따옴표 누락, 닫는 따옴표 없음
	- `Print`처럼 대문자 사용(파이썬은 대소문자 구분)

### 2.3. 실행 모드
- **대화형 모드(interactive mode)**
	- 콘솔에서 한 줄씩 입력·즉시 실행
	- 간단한 계산·테스트에 적합

- **스크립트 모드(script mode)**
	- 파일(.py)로 저장 후 한 번에 전부 실행
	- 코드가 복잡할 때 필수
