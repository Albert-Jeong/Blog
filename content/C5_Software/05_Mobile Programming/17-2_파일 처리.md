## 1. 읽기전용 파일 (raw 폴더)
- **개념**
	- 읽기 전용 파일은 `/res/raw` 폴더에 저장하여 사용
	- 개발 PC에서 작성된 텍스트 파일을 프로젝트에 포함시키는 경우에 사용
		- (주로 앱의 사용 약관 등)
	- 한글 손상 방지를 위해 인코딩을 **UTF-8**로 설정

- **접근 방법**
	- `openRawResource()` 메소드 사용
	- InputStream 클래스 반환
	- `resources`는 패키지의 리소스를 의미
	- `inputStream.available()`는 읽어올 데이터의 크기를 반환

- **핵심 코드 (MainActivity.kt)**
```kotlin
binding.tvRaw.text = ""

binding.btnRead.setOnClickListener {
    var inputStream = resources.openRawResource(R.raw.raw_test)
    var txt = ByteArray(inputStream.available())
    inputStream.read(txt)
    binding.tvRaw.setText(txt.toString(Charsets.UTF_8))
    inputStream.close()
}
```

- **작업 절차**
	1. `/res` 아래에 `raw` 폴더 생성 (Android Resource Directory, Resource type: raw)
	2. 텍스트 파일을 raw 폴더에 복사
	3. 코드에서 `R.raw.파일명`으로 접근

## 2. 외부 메모리
### 2.1. 외부 메모리 개요
- 음악, 영상, 그림, 사진 파일을 여러 앱이 공유 가능하도록 저장
- **앱 전용 외부 메모리**와 **공유 외부 메모리**로 구분
- 내장 메모리보다 큰 저장 공간 사용 가능 (SD 카드 등)

### 2.2. 외부 메모리 접근 권한 추가
- **AndroidManifest.xml**
```xml
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE"/>
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE"/>
<uses-permission android:name="android.permission.MANAGE_EXTERNAL_STORAGE" 
    tools:ignore="ScopedStorage" />

<application
    android:requestLegacyExternalStorage="true">
```

- **MainActivity.kt 권한 요청 코드**
```kotlin
if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.R) {
    if (!Environment.isExternalStorageManager()) {
        val intent = Intent(Settings.ACTION_MANAGE_ALL_FILES_ACCESS_PERMISSION)
        this.startActivity(intent)
    }
} else {
    val permissions = arrayOf(
        android.Manifest.permission.READ_EXTERNAL_STORAGE,
        android.Manifest.permission.WRITE_EXTERNAL_STORAGE
    )
    ActivityCompat.requestPermissions(this, permissions, 1001)
}
```

### 2.3. 앱 전용 외부 메모리
- **경로 확인**
	- 경로 예: `/storage/emulated/0/Android/data/com.example.rawtest/files`
	- SDK 버전, 제조사, 에뮬레이터마다 다름
```kotlin
binding.btnRead.setOnClickListener {
    val externalDir = getExternalFilesDir(null).toString()
    binding.tvRead.text = externalDir
    Log.d("path", externalDir)
}
```

- **파일 읽기**
	- raw 폴더와 달리 **`FileInputStream`** 사용
	- 경로 설정 부분만 추가, 나머지는 raw 폴더 처리와 유사
```kotlin
binding.btnRead.setOnClickListener {
    val externalDir = getExternalFilesDir(null).toString()
    val fileInputStream = FileInputStream(externalDir + "/exmem.txt")
    var txt = ByteArray(fileInputStream.available())
    fileInputStream.read(txt)
    binding.tvRead.text = txt.toString(Charsets.UTF_8)
    fileInputStream.close()
}
```

### 2.5. 디렉터리 생성/삭제
```kotlin
val externalDir = System.getenv("EXTERNAL_STORAGE") + "/test_dir"
val pathDir = File("$externalDir/test")

binding.btnMkdir.setOnClickListener {
    pathDir.mkdir()      // mkdirs()는 mkdir -p 와 동일 (중간 경로까지 생성)

```
- `mkdir()`: 디렉터리 생성
- `mkdirs()`: 상위 디렉터리까지 함께 생성 (= `mkdir -p`)

### 2.6. 폴더/파일 목록 확인
- **레이아웃: ScrollView로 TextView 감싸기**
```xml
<ScrollView
    android:layout_width="match_parent"
    android:layout_height="wrap_content">
    <TextView android:id="@+id/tvRead"/>
</ScrollView>
```

- **코드**
	- `Environment.getRootDirectory()`: 시스템 폴더(`/system`) 경로
	- `listFiles()`: 해당 경로의 파일 목록을 배열로 반환
	- `indices`: 배열의 인덱스 범위 (0..마지막)
	- 파일 확인: `isFile()` / 폴더 확인: `isDirectory`
```kotlin
binding.btnFilelist.setOnClickListener {
    val sysDir = Environment.getRootDirectory().absolutePath  // /system
    var sysFiles = File(sysDir).listFiles()
    var strFileName: String
    for (i in sysFiles.indices) {
        if (sysFiles[i].isDirectory == true)
            strFileName = "<폴더> " + sysFiles[i].toString()
        else
            strFileName = "<파일> " + sysFiles[i].toString()
        binding.tvRead.text = binding.tvRead.text.toString() + "\n" + strFileName
    }
}
```

## 3. 실습: 간단 이미지 뷰어 만들기
- **기능**: 외부 메모리(`/sdcard/test_dir`)의 이미지 파일을 버튼으로 전환하며 보기

### 3.1. 파일 준비
- 이미지 파일 (renoir01.png ~ renoir10.png): 외부 저장소 `/sdcard/test_dir`
- 배경 이미지 (background.jpg): `res/drawable` 폴더

### 3.2. 화면 디자인 (activity_main.xml)
```xml
<LinearLayout
    android:orientation="vertical"
    android:background="@drawable/background">
    
    <LinearLayout android:orientation="horizontal">
        <Button android:id="@+id/btnPrev"
            android:layout_weight="1"
            android:text="이전 그림"/>
        <Button android:id="@+id/btnNext"
            android:layout_weight="1"
            android:text="다음 그림"/>
    </LinearLayout>
    
    <ImageView
        android:id="@+id/imgPicture"
        android:layout_weight="1"/>
</LinearLayout>
```

### 3.3. 기능 구현 (MainActivity.kt)
- **필드 선언 및 파일 목록 가져오기**
	- `"renoir"`로 시작하는 파일만 필터링
```kotlin
class MainActivity : AppCompatActivity() {
    var curNum = 0
    var imgFiles = mutableListOf<File>()
    
    // onCreate 내부
    val sysDir = System.getenv("EXTERNAL_STORAGE") + "/test_dir"
    var sysFiles = File(sysDir).listFiles()
    
    for (i in sysFiles.indices) {
        if (sysFiles[i].isFile == true && 
            sysFiles[i].toString().replace(sysDir + "/", "").startsWith("renoir")) {
            imgFiles.add(sysFiles[i])
        }
    }
}
```

- **이미지 표시 및 버튼 동작**
	- `BitmapFactory.decodeFile()`: 파일 경로로부터 Bitmap 생성
	- `abs(curNum % 10)`: 인덱스가 음수가 되거나 범위를 벗어나는 것 방지
```kotlin
binding.imgPicture.setImageBitmap(
    BitmapFactory.decodeFile(imgFiles.get(curNum).toString())
)

binding.btnNext.setOnClickListener {
    curNum++
    binding.imgPicture.setImageBitmap(
        BitmapFactory.decodeFile(imgFiles.get(abs(curNum % 10)).toString())
    )
}

binding.btnPrev.setOnClickListener {
    curNum--
    binding.imgPicture.setImageBitmap(
        BitmapFactory.decodeFile(imgFiles.get(abs(curNum % 10)).toString())
    )
}
```
